# Scribe Phase 0 — Sync Spike Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the real Xcode project (iOS + macOS app, widget extension, shared Core package, entitlements) and use a throwaway probe to answer the five sync questions in spec §14 before any product code is written.

**Architecture:** XcodeGen generates one multiplatform app target (`Scribe`, iOS + macOS) and one multiplatform widget extension (`ScribeWidgets`), both depending on the local Swift package `ScribeCore`. A temporary `ProbeNote` SwiftData model lives in a shared App Group store; the main app syncs it with CloudKit while the widget extension and App Intents only read/write the file. A probe screen logs every CloudKit event so a person can time how changes travel between an iPhone and a Mac. After the measurements are recorded, all probe code is deleted; the project scaffold stays.

**Tech Stack:** Swift 6, SwiftUI, SwiftData + CloudKit, WidgetKit, App Intents, XcodeGen 2.46, Xcode 27 (iOS 27 / macOS 27 SDKs), Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-05-scribe-v1-design.md` (§4 Architecture, §12 Sync, §14 Risks and Phase 0 Questions, §16 Build Phases)

## Global Constraints

- Deployment targets: iOS 26.0 and macOS 26.0. iPhone only (`TARGETED_DEVICE_FAMILY` = `1`); no iPad layout.
- Swift language mode 6 (`SWIFT_VERSION: "6.0"`).
- Bundle IDs: `com.noamchuri.scribe` (app), `com.noamchuri.scribe.widgets` (widget extension).
- App Group: `group.com.noamchuri.scribe`. iCloud container: `iCloud.com.noamchuri.scribe`. Team: `X74V85W2JX`.
- Only the main app runs CloudKit sync; the widget extension and intents open the same store without CloudKit.
- `Scribe.xcodeproj` is generated by XcodeGen and is never committed (`.gitignore` already has `*.xcodeproj`). `App/Info.plist` and `Widgets/Info.plist` are generated by XcodeGen and ARE committed.
- Every `xcodebuild`/`swift` command runs with `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` (the active developer dir on this Mac is the Command Line Tools).
- Build output goes to `build/` (git-ignored): always pass `-derivedDataPath build/dd`.
- No third-party packages in Phase 0.
- The repo is public: never commit tokens, keys, provisioning profiles or personal data.
- Probe code lives only in `Spike/` and is deleted in Task 5. `Core/` must never import or reference it.
- The author's real devices are operated by the author. Do not drive them with UI automation unless the author asks; give exact instructions and record what they report.
- Work on branch `phase0-sync-spike` (create it from `main` before Task 1).

## Review Focus

Failure modes the spec implies but no automated test exercises. Each line is pinned by a measurement step in Task 4.

1. **App force-quit on iPhone, then a write from the widget or Siri** — the change must still reach the Mac at the latest after the iPhone app next opens (Task 4, M3/M4).
2. **Device offline while adding** — nothing is lost; the change syncs within a minute of reconnecting (Task 4, M8).
3. **Rapid writes (three adds within five seconds)** — all three arrive on the other device exactly once (Task 4, M1).
4. **iPhone in Low Power Mode** — background pushes may be delayed; record the delay instead of assuming instant sync (Task 4, M2).
5. **Mac app not running** — the Mac widget still shows the store contents and catches up once the app launches (Task 4, M7).

`Spike/Shared/ProbeStore.swift`. Each process creates exactly one container; only the main app turns on CloudKit. Every note's text records which process wrote it, which answers "where did this intent run?":

```swift
import Foundation
import ScribeCore
import SwiftData
import WidgetKit

struct ProbeSummary: Sendable {
    let total: Int
    let latest: [String]
}

/// Phase 0 only. One container per process: the main app syncs with
/// CloudKit, the widget extension only reads/writes the shared file.
enum ProbeStore {
    static let isMainApp = Bundle.main.bundleURL.pathExtension == "app"
    static let processLabel = isMainApp ? "app" : "extension"

    static let container: ModelContainer = {
        let config = ModelConfiguration(
            "ScribeProbe",
            groupContainer: .identifier(ScribeIDs.appGroup),
            cloudKitDatabase: isMainApp ? .private(ScribeIDs.cloudKitContainer) : .none
        )
        do {
            return try ModelContainer(for: ProbeNote.self, configurations: config)
        } catch {
            fatalError("Probe store failed to open: \(error)")
        }
    }()

    /// Text records who wrote it, from which process, and when.
    static func add(source: String) throws {
        let context = ModelContext(container)
        let stamp = Date.now.formatted(date: .omitted, time: .standard)
        context.insert(ProbeNote(text: "\(source) via \(processLabel) @ \(stamp)"))
        try context.save()
        WidgetCenter.shared.reloadAllTimelines()
    }

    static func summary() -> ProbeSummary {
        let context = ModelContext(container)
        var latest = FetchDescriptor<ProbeNote>(sortBy: [SortDescriptor(\.createdAt, order: .reverse)])
        latest.fetchLimit = 3
        let total = (try? context.fetchCount(FetchDescriptor<ProbeNote>())) ?? -1
        let texts = ((try? context.fetch(latest)) ?? []).map(\.text)
        return ProbeSummary(total: total, latest: texts)
    }
}
```

`Spike/App/SyncEventLog.swift` (answers Q3: are CloudKit events and remote-change notifications observable under SwiftData?):

```swift
import CoreData
import Foundation
import Observation

/// Phase 0 only. Answers spec §14 Q3: can we observe CloudKit sync events
/// and remote-change notifications while using SwiftData?
@MainActor
@Observable
final class SyncEventLog {
    struct Entry: Identifiable {
        let id = UUID()
        let at: Date
        let text: String
    }

    private(set) var entries: [Entry] = []
    private(set) var remoteChangeCount = 0
    @ObservationIgnored private var observers: [NSObjectProtocol] = []

    init() {
        let center = NotificationCenter.default
        observers.append(center.addObserver(forName: NSPersistentCloudKitContainer.eventChangedNotification, object: nil, queue: .main) { [weak self] note in
            let text = Self.describe(note)
            MainActor.assumeIsolated { self?.append(text) }
        })
        observers.append(center.addObserver(forName: .NSPersistentStoreRemoteChange, object: nil, queue: .main) { [weak self] _ in
            MainActor.assumeIsolated {
                guard let self else { return }
                self.remoteChangeCount += 1
                self.append("remote change #\(self.remoteChangeCount)")
            }
        })
    }

    nonisolated static func describe(_ note: Notification) -> String {
        guard let event = note.userInfo?[NSPersistentCloudKitContainer.eventNotificationUserInfoKey] as? NSPersistentCloudKitContainer.Event else {
            return "cloudkit event (unreadable)"
        }
        let type = switch event.type {
        case .setup: "setup"
        case .import: "import"
        case .export: "export"
        @unknown default: "other"
        }
        guard event.endDate != nil else { return "\(type) started" }
        return event.succeeded ? "\(type) succeeded" : "\(type) FAILED: \(event.error?.localizedDescription ?? "unknown")"
    }

    private func append(_ text: String) {
        entries.insert(Entry(at: .now, text: text), at: 0)
    }
}
```

```swift
                    LabeledContent("Last refresh", value: lastRefresh.formatted(date: .omitted, time: .standard))

                        Text(errorText).foregroundStyle(.red)
                    }

                            Text(entry.at.formatted(date: .omitted, time: .standard)).monospacedDigit()
                            Text(entry.text)
                        }
                        .font(.caption)
                    }
                }
            }
            .navigationTitle("Scribe Sync Probe")
        }
        .onAppear(perform: refresh)
        .onChange(of: scenePhase) { _, phase in
            if phase == .active { refresh() }
        }
        .onChange(of: log.remoteChangeCount) { refresh() }
    }

    private func add() {
        do {
            try ProbeStore.add(source: "\(deviceName) app button")
            refresh()
        } catch {
            errorText = "Add failed: \(error)"
        }
    }

    private func refresh() {
        let context = ModelContext(ProbeStore.container)
        var latest = FetchDescriptor<ProbeNote>(sortBy: [SortDescriptor(\.createdAt, order: .reverse)])
        latest.fetchLimit = 20
        do {
            total = try context.fetchCount(FetchDescriptor<ProbeNote>())
            rows = try context.fetch(latest).map { Row(id: $0.id, text: $0.text) }
            lastRefresh = .now
            errorText = nil
        } catch {
            errorText = "Refresh failed: \(error)"
        }
    }
}
```
